### Pregunta 2:
Que patron de diseño usaria?
Facade

Explique en 2 o 3 líneas por qué considera que este patrón es apropiado.
Facade es el patron que sirve como fachada de un sistema complejo sin que el cliente final tenga que conocer el funcionamiento ni los procesos internos que se llevaron a cabo para obtener un resultado.

### Pregunta 3:
Que patron de diseño usaria?
Proxy

Explique por qué:
Este patrón es el que se usa cuando se desea controlar quien tiene acceso a cada parte de nuestro sistema. Con el se pueden hacer las respectivas validaciones de permisos.

### Pregunta 4:
Que patron de diseño usaria?
Adapter

Explique cual es el problema que debe resolver el patrón:
La integración de librerias externas con el propio sistema creado que son incompatibles. Lo que hace es convertir una interfaz en otra.
